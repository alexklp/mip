# Постійні правила роботи

- Працювати лише всередині кореня цього репозиторію.
- Не читати secrets, credentials, `.env`, дані автентифікації SSH/Codex та файли поза коренем репозиторію.
- PostgreSQL за замовчуванням використовувати лише read-only; DML і DDL заборонені без окремого дозволу.
- Не використовувати sudo, systemctl, kill, не змінювати ОС і не виконувати глобальні встановлення.
- Не звертатися до llama-server.
- Не додавати нові залежності без дозволу.
- Commit, push, merge, rebase та інші Git-операції зі зміною стану виконувати лише після явного дозволу.
- Не змінювати коректні сусідні компоненти й не робити супутній рефакторинг.
- Код, коментарі та службову документацію в коді писати українською; технічні ідентифікатори контрактів і API зберігати сумісними.
- Перевірені code/schema/runtime мають вищий пріоритет за historical notes та припущення.
- Обмеження конкретної фази користувача мають пріоритет; дозвіл на реалізацію не означає дозволу на live DB, запуск сервісів чи інтеграційних тестів.
